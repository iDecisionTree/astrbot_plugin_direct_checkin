# v1.1 代码检查与改版说明

## 业务修正

| 原问题 | 修正与验证 |
| --- | --- |
| 扣减后复用计次序号，补打卡触发唯一约束 | 历史最大序号递增，净次数只用于额度；回归覆盖扣减后补打卡 |
| 扣减检查与写入分离、末位管理员竞态 | 同一个 SQLite 写事务内检查并写入，并发测试验证 |
| 消息 ID 跨机器人／会话冲突，管理员事件可重放 | 含平台、机器人、会话、消息 ID 的键；短操作与回执同事务，打卡／重置持久化接收与结果 |
| 同一请求多次取时间，跨周归档与计次不一致 | 接收时间 ContextVar 贯穿请求；暂停统一左闭右开 |
| 后续失败可能覆盖成功状态 | 定稿仅从 PENDING 转换，最后提交时间同事务；异常处理不覆盖成功记录 |
| 旧库索引先于补列，人工历史 counted 缺失 | schema v2 事务迁移、原子生成迁移前备份；按历史 2 次规则重放旧人工记录 |
| 配置改变重算历史周 | 每周目标持久化，历史补 2，本周首次固定 |
| 高相似有新增内容也被直接拒绝 | 保留风险并附本人历史差异交 AI；完全重复仍拦截 |
| Word 段落及表格顺序丢失 | 依正文顺序提取，保留段落供长文筛选 |
| 模型字段／无限值未校验，规则与材料混合 | system_prompt 固定规则，待审内容为 JSON；字段类型及有限数值校验、有限重试 |
| 临时文件清理可能删除共享文件 | 借用适配器源文件不删除；归档副本验证、失败只清理自有文件 |
| 重置先删文件，失败无法恢复或提示不真实 | NAS 同目录暂存 + 恢复日志 + 数据库提交标记；失败恢复或明确残留待清理 |
| 文本在 Excel 被当公式、QQ／学号丢前导零 | 明确字符串类型、文本格式和 quotePrefix；覆盖公式样式文本与前导零 |
| 统计 0／1／2 分类写死，累计与材料混淆 | 共用快照，任意目标的三类人数；每周封顶累计与材料、人工调整分列 |

## 实现边界

- 正常请求可并发；重置使用进程内维护屏障。每个数据库及 NAS 专用目录仅运行一个插件实例。
- 普通管理员修改和回复回执同事务提交。打卡及重置跨文件／模型操作，先持久化接收状态；崩溃中断的回执不会自动重做，提示使用新消息并核对。
- 迁移前备份为数据库相邻的 `*.before-v2.db`；只在升级时创建。此备份不包含 NAS 文件。
- `reset-journal.json` 保存 NAS 路径、操作 ID、待处理文件名；数据库 `reset_commits` 判断是否已清库。保留管理员、事件回执和提交标记是恢复与防重放的必要条件。
- 图片和 Excel 渲染在线程中运行，限制并发，唯一文件名与原子保存。Matplotlib 使用随包 Noto 字体和 Agg，不要求显示服务。
- 个人报表仅含目标用户指标，暂停记录是全员共用规则背景。
