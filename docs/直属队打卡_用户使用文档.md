# 直属队学习打卡使用指南

词九会帮你保存学习记录、审核内容，并告诉你本周的打卡进度。第一次使用，按下面的步骤操作即可。

## 1. 首次绑定身份

在 QQ 群中发送：

```text
/d 学号 姓名
```

例如：

```text
/d 2026123456 张三
```

收到绑定成功的回复后，以后无需重复绑定。请填写真实学号与姓名；一个 QQ 只能绑定一个学号，一个学号也只能绑定一个 QQ。绑定信息填错时，请联系队伍负责人处理。

## 2. 提交学习记录

1. 将本次学习记录整理成 **.docx 格式的 Word 文档**，上传到 QQ 群。
2. **引用这条文件消息**，发送 `/d`。
3. 等待词九回复，确认本次是否审核通过、是否计入本周次数。

只上传文件不会自动打卡；需要引用文件并发送 `/d`。请引用文件消息本身，不要引用文件截图或聊天文字。

支持 `.docx`，不支持旧版 `.doc`。文件默认大小上限为 20 MiB；如果提示过大，请压缩文档中的图片后重新提交。

## 3. 学习记录写什么

不要求固定模板或字数，但要让人看出你实际做了什么。建议包括：

- **学习内容**：这次学习了哪些知识，或推进了哪个项目。
- **实际过程**：实现了什么功能、做了什么实验、解决了什么问题。
- **验证结果**：如何测试，得到什么结果，有什么收获或下一步计划。

可以配代码、截图和表格，但请同时写清楚文字说明。只有图片、资源链接或空泛总结，可能无法通过审核。

同一项目可以持续提交。请突出本次新增的功能、修复、测试或结论；不要重复提交相同内容。材料与之前相似时，有清楚的实质性新进展仍可以通过。

## 4. 每周怎样计次

- 默认每周需要完成 **2 次**有效打卡，实际目标可发送 `/d help` 查看。
- 按北京时间计算，一周从周一 00:00 开始，到下周一 00:00 前结束。
- **同一天最多计 1 次**。默认目标为 2 次时，请安排在两个不同的自然日提交。
- 同一天再次提交，或本周已经满额后提交，审核通过仍会保存为**额外学习记录**，但不增加本周次数。
- 额外材料不能补其他周的缺卡。
- 打卡所属日期与周次按词九接收到请求的时间确定，不因审核等待跨过午夜而改变。

例如：周二审核通过并计次一次，周二再提交一份有效材料只作额外记录；周四再次审核通过并计次后，本周进度为 `2/2`。

## 5. 看懂词九的回复

回复中的“今天第 X 位来打卡的同学”，按全队当天首次提交材料并保存的顺序计算。同一天重试或追加材料沿用原序号，下一天重新编号。这是参与顺序，不是审核通过或成功计次的排名；是否计次仍以回复中的进度为准。

| 回复情况 | 说明与处理方法 |
| --- | --- |
| 打卡成功，本周 `1/2` 等进度 | 本次已计次；分母是本周目标 |
| 本周已完成 | 已达到本周目标 |
| 保存为额外学习记录 | 内容通过并保存，本次不增加计次 |
| 和之前提交的内容一致 | 本次不计次；请提交有实际新增进展的材料 |
| 内容审核不通过 | 根据反馈补充学习过程和验证结果，再重新提交 |
| 审查服务异常，文档已保存 | 暂时未计次；稍后引用原文件，重新发送一条 `/d` 重试 |
| 文件无法下载或无法打开 | 重新上传有效的 `.docx`，再引用文件打卡 |
| 今天或本周暂停打卡 | 按群内通知安排，恢复接收后再提交 |
| 维护中或其他技术问题 | 稍后再试；结果不明确时，先请负责人核对，避免反复提交 |

当天暂停不会自动免除本周任务；若明确提示“本周不按缺卡处理”，则本周属于豁免周。具体安排以词九回复和群通知为准。

审核服务异常不等于内容不合格。暂时没有收到回复时，也不代表已成功计次，请以最终回复为准；长时间没有结果可联系负责人核对。

## 6. 查看帮助

发送：

```text
/d help
```

日常只需记住三个用法：**`/d 学号 姓名` 绑定、引用文档发送 `/d` 打卡、`/d help` 查看帮助。**
